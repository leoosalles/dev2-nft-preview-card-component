<h1>NFT Preview Card Component</h1>
<h2>Overview</h2>
<p>
  This project is a frontend challenge from <strong>Frontend Mentor</strong>, aimed at practicing core HTML and CSS skills. The task was to build a responsive and visually accurate NFT preview card component based on a provided design. The card features an NFT called Equilibrium #3429 and includes modern layout techniques such as <strong>flexbox, responsive design for different screen sizes, CSS hover states, and custom variables</strong>.
</p>
<p>
It’s a beginner-friendly project focused on mastering layout structure, styling consistency, and interactive UI elements without using JavaScript.
</p>
<h2>Features ✨</h2>
<p>
  ✅ Clean and minimal design
</p>
<p>
  ✅ Hover effects for interactive elements
</p>
<p>
  ✅ Typography using Google Fonts
</p>
<p>
  ✅ Color palette managed with CSS variables
</p>
<p>
  ✅ Flexbox-based alignment for responsiveness
</p>
<h2>Technologies Used 🛠️</h2>
